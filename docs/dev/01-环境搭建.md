# 01 · 环境搭建（macOS）

一次性步骤，做完后日常只需看 `02-构建与运行.md`。

## 工具链

| 工具 | 安装 | 用途 |
| --- | --- | --- |
| Xcode（完整版，非 CLT） | App Store | iOS 构建 |
| Node ≥ 20 | `brew install node` | Expo / Metro |
| CocoaPods | `brew install cocoapods` | iOS 原生依赖 |
| protobuf | `brew install protobuf` | `protoc`，生成 Python / C++ 绑定 |
| swift-protobuf | `brew install swift-protobuf` | 生成 Swift 绑定（M1 起需要） |
| Python ≥ 3.10 + uv | `brew install uv` | PC 端网关 |

### 让命令行使用 Xcode（必须）

装完 Xcode 后 `xcode-select` 可能仍指向 CommandLineTools，`xcodebuild`、`simctl`、`pod` 都会出错：

```bash
sudo xcode-select -s /Applications/Xcode.app
xcodebuild -version   # 应显示 Xcode 版本而不是报错
```

### CocoaPods 要求 UTF-8

在 `~/.zshrc` 里加一行，否则 `pod install` 会报 encoding 警告或失败：

```bash
export LANG=en_US.UTF-8
```

## 真机调试（免费 Apple ID 即可）

不需要付费 Developer Program。免费账号的限制：App 签名 7 天过期要重装、最多 3 台设备、每周最多 10 个 Bundle ID。

1. **手机**：设置 → 隐私与安全性 → 开发者模式 → 打开（会重启）。用数据线连 Mac，解锁并"信任此电脑"。
2. **Xcode 登录 Apple ID**：Xcode → Settings → Accounts → `+` → Apple ID。
3. **首次生成证书和描述文件只能在 Xcode 图形界面做**：
   - `open mobile/ios/iMuninn.xcworkspace`
   - 左侧选 iMuninn 工程 → TARGETS iMuninn → Signing & Capabilities
   - 勾选 Automatically manage signing，Team 选 "你的名字 (Personal Team)"
   - 顶部设备选 iPhone，按 ⌘R
   - 手机上若提示"不受信任的开发者"：设置 → 通用 → VPN与设备管理 → 信任
4. 之后命令行 `npx expo run:ios --device` 就能直接用了（描述文件已缓存在本机）。

Team ID 已写在 `mobile/app.config.ts` 的 `ios.appleTeamId`，换账号时改这一处。

## 仓库首次初始化

```bash
git clone <repo> imuninn && cd imuninn
tools/gen-proto.sh                              # 生成协议绑定
cd host/python && uv venv && uv pip install -e ".[dev]" && cd ../..
cd mobile && npm install && cd ..
```
