# 04 · M1 使用方法：位姿 + IMU 实时流

M1 之后手机能把 ARKit 位姿和 CoreMotion IMU 实时发到 PC，PC 可以远程改手机参数。

## 跑起来

1. PC：`cd host/python && source .venv/bin/activate && imuninn watch --start`
   （只看速率不看数据：`imuninn gateway`）
2. 手机：打开 iMuninn → "发现的网关"里点 PC 的名字（第一次会弹本地网络权限，允许）。
   找不到就手输 `PC的IP:7420`。
3. 连上后 PC 端 `--start` 会自动开始采集；也可在手机上点"开始采集"。
4. 断线会自动重连（1→10 s 退避），点"断开"才停止。

手机和 PC 必须在同一局域网。Debug 包还要连 Metro（见 02）。

## Python API

```python
import imuninn

with imuninn.open() as s:            # 启动网关（mDNS + 控制通道 + UDP）
    dev = s.wait_for_device()        # 等手机连上并完成握手、时钟同步
    dev.set("imu.rate_hz", 50)       # 远程改参数；返回 ConfigResult
    dev.set("ar_pose.exposure_locked", True)
    dev.set("ar_pose.enabled", False)
    dev.start()                      # = SessionControl START

    for pose in s.iter("ar_pose"):   # 迭代器；s.iter() 不带参数则给 (stream, sample)
        t_pc = s.to_pc_time(dev, pose.header.device_time_ns)   # 对齐到 PC 时钟（秒）
        print(t_pc, pose.position, pose.orientation, pose.intrinsics.fx)

    s.on("imu", lambda imu: ...)     # 回调方式（在网关线程上执行，要快）
    print(dev.stats)                 # 每个流的计数、丢包、速率
```

参数 key 的规则：`session.mode`、`<流>.enabled`、`<流>.<参数>`。可用参数看 `dev.capabilities`（每个带类型、范围、生效方式），当前有：

| key | 类型 | 生效 |
| --- | --- | --- |
| `imu.rate_hz` | int 10–200，步长 10 | 即时 |
| `ar_pose.video_format` | enum，如 `1920x1440@60` | 重启会话 |
| `ar_pose.exposure_locked` | bool | 即时 |
| `ar_pose.focus_locked` | bool | 重启会话 |
| `session.mode` | `ar` / `camera` | camera 模式 M4 才实现，现在会被拒绝 |

超出范围的值会被钳位（status = clamped），非法值被拒绝（rejected + reason）。

## 数据语义

- 位姿：ARKit 原生约定（右手系、Y 上、相机朝 -Z），世界原点是会话开始时相机位置。
- 内参随每帧位姿发送（`PoseSample.intrinsics`），分辨率是 ARKit 图像分辨率。
- IMU：`accel` 是重力 + 用户加速度（m/s²，设备坐标系），`gyro` 是 CoreMotion 偏置校正后的角速度（rad/s）。
- 时间戳：设备单调时钟（开机起算，纳秒），与 ARKit 帧同一时基。`s.to_pc_time()` 用握手时的 NTP 式估计转到 PC 墙钟。

## 实测（iPhone 17 Pro ↔ MacBook，Wi‑Fi）

- IMU 100 Hz、位姿 60 Hz，1000+ 样本零丢包
- 控制通道往返 7–10 ms
- 改 IMU 采样率即时生效；关/开位姿流即时生效
