# iOS App

从 App Store 安装：<https://apps.apple.com/app/id6832343388>。

手机是服务端：打开 App 就发布 Bonjour 服务 `_imuninn._tcp` 并监听 7420（控制）和 7422（数据），PC 来连。App 必须在前台，进后台系统会停掉相机。

## 界面

| 区域 | 内容 |
| --- | --- |
| 顶部状态胶囊 | 服务状态与已连接的 PC 数；点一下弹出已连接 PC 列表（订阅的流、丢包、谁在控制）。被远程控制时显示「xxx 控制中 · 接管」，点一下收回控制权 |
| 预览 | 相机画面（AR 模式带 ARKit 渲染），固定 3:4 框；右下角「小窗 / 大窗」「全屏」 |
| 采集 | 开始 / 停止采集、预览开关、黑屏模式；追踪状态、位姿 / IMU / 视频 / 深度实时速率、编码丢帧 |
| 服务 | Bonjour 名称（可改，留空用设备名；修改后服务重启，已连接的 PC 需要重连）、每个网卡的地址（`en0` Wi‑Fi；插 USB 时多一个 `169.254.x.x` 直连地址，地址行可选中复制） |
| 配置 | 全部参数，和 PC 端改的是同一份；显示当前预设或「未保存的预设」；数字可直接输入，↻ 标记的参数会重启会话 |
| 配置预设 | 存 / 应用 / 长按删除本机预设 |
| 设置 | 外观（跟随系统 / 浅色 / 深色）、语言（跟随系统 / 中文 / English） |

## 黑屏模式

长时间推流时点「黑屏模式」：5 秒无操作后屏幕纯黑并降到最低亮度，采集照常，点一下屏幕临时唤醒。OLED 上屏幕功耗接近零，发热明显降低。PC 端 `dev.set("session.black_screen", True)` 是同一个开关。

## 常见情况

- 顶部显示「网络错误」：切到后台又回来时监听端口被系统回收，App 会在 2 秒内自动重建；如果持续，看 Wi‑Fi 是否断了。
- 切模式 / 换镜头 / 改分辨率 / 开关深度会重启采集约 1 秒，这是正常的。
- 第一次打开要允许「本地网络」权限，否则 PC 发现不了手机。
